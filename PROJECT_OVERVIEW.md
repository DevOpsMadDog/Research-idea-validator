## 🚀 Quick Start

### Run the Debate System

```bash
python3 orchestrator.py
```

This will:
1. Initialize 4 specialized agents + 1 judge
2. Run 5 debate phases (Opening, Rebuttals, Cross-Examination, Closing)
3. Score 20 arguments automatically
4. Generate judge's final verdict
5. Export results to JSON files

**Expected Runtime**: ~30 seconds (simulates 45-60 min debate)

## 🎭 The Debate Process

### Phase 1: Opening Arguments
Each agent presents their proposal:
- **Product Visionary**: Fractional ownership (₹100 entry), Vernacular AI, Emergency credit pools
- **Market Analyst**: BNPL for services (₹2.5T market), Gig worker insurance, MSME credit
- **Risk Manager**: Regulated micro-savings (low-risk approach)
- **Tech Architect**: Real-time credit, Vernacular voice, **Federated dashboard** ⭐

### Phase 2: First Rebuttal Round
Agents challenge each other's assumptions:
- Product Visionary defends bold vision against "too risky" criticism
- Market Analyst stresses unit economics and market timing
- Risk Manager warns of regulatory dangers (Paytm example)
- Tech Architect questions technical feasibility of fractional ownership

### Phase 3: Cross-Examination
Direct questioning between agents:
- 16 specific, pointed questions
- Focus on unit economics, regulatory timeline, technical challenges
- Expose weaknesses in proposals

### Phase 4: Intense Second Rebuttal
Heated exchanges as agents defend their positions:
- Product Visionary appeals to moral imperative
- Market Analyst provides market precedents
- Risk Manager cites failed startups
- Tech Architect demonstrates cost breakdowns

### Phase 5: Closing Arguments
Final positions and comprehensive proposals:
- Each agent presents their ultimate recommendation
- Judge evaluates all arguments
- **Final scores calculated**
