# 🧠 COMPRESSED CURSOR.AI PROMPT
## Multi-Agent Debate + Final Judge (Financial Product Validation - India)

---

## IDEA
**Money Operating System / Capital OS (India)**
Holistic money management system (not products) for Indian HNIs/business owners. Optimizes cash-flow timing, dynamic capital allocation across 5 buckets (Survival, Opportunity, Growth, Yield, Optionality), tax-first, cycle-aware, engineers exits. Revenue: Subscription + advisory fee. No commissions.

---

## AGENTS (Run Sequentially)

### AGENT 1: Skeptical VC (India)
**Goal:** Kill the idea if possible
**Evaluate:** TAM, scalability, defensibility, sales cycle, exit potential
**Format:**
- Initial Position (5 bullets)
- Top 3 Fatal Risks
- What Would Change My Mind

### AGENT 2: SEBI Regulatory Expert
**Goal:** Worst-case SEBI scrutiny
**Evaluate:** RIA/PMS/AIF/advisory legality, fee structure, conflict of interest, regulatory shutdown risk
**Format:** Same as Agent 1

### AGENT 3: Behavioral Finance Expert (Indian Psychology)
**Goal:** Cynical realism about Indian money behavior
**Evaluate:** Trust barriers, willingness to pay, override risk, RM/bank inertia
**Format:** Same as Agent 1

### AGENT 4: Execution Realist (Ex-Fintech Operator)
**Goal:** Operational reality check
**Evaluate:** Complexity, cost structure, hiring, time to revenue, compliance overhead
**Format:** Same as Agent 1

### AGENT 5: Bull Case Architect
**Goal:** Defend rigorously (no hype)
**Evaluate:** New category, defensibility, wedge use-case, pricing power, moat
**Format:** Same as Agent 1

### AGENT 6: FINAL JUDGE (Investment Committee Chair)
**Goal:** Meta-evaluation, decide based on evidence

**STEPS:**
1. **Normalize:** Extract facts/risks from each agent (≤5 bullets each)
2. **Conflict Analysis:** Agreements, disagreements, material conflicts
3. **Score (0-10):** Market Pain, Differentiation, Regulatory Safety, Execution Feasibility, Wealth Potential (₹100-500 Cr ARR)
4. **Kill-Shot Risk:** Single biggest 24-month risk (Regulatory/Behavioral/Structural/Distribution/Trust)
5. **Category:** New Category / Tech-Advisory / Premium Repackaging / Not a Business
6. **VERDICT:** ✅ APPROVE | ⚠️ CONDITIONAL | ❌ REJECT (≤5 bullets)
7. **If NOT Rejected:** Minimum wedge product, first customer persona, 90-day proof points
